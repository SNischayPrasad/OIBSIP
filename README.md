# OIBSIP

Projects completed during the **Oasis Infobyte Internship Program (OIBSIP)**, Data Science track.

**Live demo website:** https://nischay-oibsip-data-science.vercel.app (try all three models in your browser; source in [`website/`](website)).

| Task | Project | Highlights |
|---|---|---|
| Task 1 | [Iris Flower Classification](DataScience-Task1-IrisFlowerClassification) | 4 classifiers compared; KNN best (96.7% CV accuracy) |
| Task 4 | [Email Spam Detection](DataScience-Task4-EmailSpamDetection) | TF-IDF + Naive Bayes, 98.8% accuracy, 0.95 spam F1 |
| Task 5 | [Sales Prediction](DataScience-Task5-SalesPrediction) | Polynomial regression, R² = 0.987; TV drives the most sales |

Each folder contains a commented Jupyter notebook, a README with results, the dataset (where needed) and
an `outputs/` folder with the saved plots and metrics.
